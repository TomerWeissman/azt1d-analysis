## How to read a week folder

1. `README.md` first: hypotheses, findings, outcomes, work done, the file list, and what to remember.
2. `notebooks/`: each notebook's first heading is its title. Numbering restarts each week.
3. `scripts/`: the code that builds the notebooks or runs the experiments.
4. `results/` and `figures/`: saved outputs of the scripts.
5. `docs/`: written drafts.
